# Shared spatial adapters

This package supplies the V-JEPA encoder, AC model, LingBot native trainer/inference adapter, CAD/IK mechanics, and checkpoint utilities. Run current experiments through `experiments.vjepa_expansion` and `experiments.lingbot_expansion`; both use the same 50 Stewart and 50 Delta test identities with three conditions and three seeds.

See the [reproduction guide](../../docs/reproduction.md) for preparation, training, prediction and measurement commands.
