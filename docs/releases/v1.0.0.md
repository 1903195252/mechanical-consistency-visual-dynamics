# v1.0.0 — Public code and artifact release

Companion release for [Beyond Geometric Closure: Measuring and Diagnosing
Mechanical Consistency in Visual Dynamics](https://arxiv.org/abs/2610.24619),
by Qibin Gu and Yunfeng Yan.

This release provides the experiment code, frozen protocols, numerical results,
independent SI evaluator, reproducibility tools, and manuscript sources.
Original source code is licensed under MIT. Original datasets, observations,
trajectories, predictions and numerical evidence are licensed under CC BY 4.0.
Third-party model components retain their applicable upstream terms; the
component mapping and license texts accompany the repository.

The 24 artifact packages are publicly downloadable from three existing Zenodo
records, totaling 137.13 GB:

- [Datasets and spatial evaluation](https://doi.org/10.5281/zenodo.23448115):
  9 packages, 41.66 GB.
- [Trained models and planar experiments](https://doi.org/10.5281/zenodo.23448170):
  8 packages, 47.54 GB.
- [Pretrained dependencies and continuation states](https://doi.org/10.5281/zenodo.23448172):
  7 packages, 47.93 GB.

Download the packages needed for an experiment and follow
[the import instructions](../data.md). Split archives are imported directly
from their `.tar.parts.json` descriptors without creating a merged archive.

The CPU verification workflow passed 37 tests and checked 12,956 continuous-score
rows, four planar model/resolution settings, 900 V-JEPA + AC forecasts, and
1,800 LingBot videos against the recorded aggregates. It can be reproduced with:

```bash
./setup.sh
./run.sh verify
```

These checks validate the released evaluator, result aggregates, and artifact
tools. They do not rerun model training or download the complete artifact collection.
